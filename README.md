# Expense Tracker

A simple Expense Tracker project built using Python.

## Features
- Add new expenses
- View all expenses
- Calculate total spending
- Exit the application

## Technologies Used
- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python expense_tracker.py
```

## Project Type
Beginner Python Console Application
